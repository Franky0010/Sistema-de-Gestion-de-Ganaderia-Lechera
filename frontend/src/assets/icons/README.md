# Google Material Symbols

SVG oficiales de Google Material Symbols Outlined, tamaño óptico de 24 px.
Origen: https://github.com/google/material-design-icons/tree/master/symbols/web

Iconos utilizados: eco, agriculture, group, add, arrow_back y logout.
Licencia Apache-2.0, incluida en LICENSE. El frontend añade atributos de
accesibilidad y `fill="currentColor"` al insertarlos. Los archivos se sirven localmente.
